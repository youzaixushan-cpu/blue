# Git workflow

This repo is connected to a GitHub remote (`origin`). After completing any significant change (a new feature, a meaningful redesign, a multi-file refactor), create a commit for it without waiting to be asked each time — build up history incrementally as work lands, using clear, conventional commit messages. Small/trivial tweaks can be batched into the next commit rather than committed individually. Never push or force-push without being asked; committing locally is pre-authorized, pushing is not.
